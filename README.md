### 📊 Project 1: Strategic Sales Data Analysis (Excel)
**Module:** Data Summarization & Excel Fundamentals

**Key Skills:** `Pivot Tables`, `SUMIFS/COUNTIFS`, `XLOOKUP`, `Strategic Reporting`.  
**Outcomes:**
