# 📊 Sales Data Analysis | Data Summarization Module

## 🎓 Course Context
This project serves as the capstone assessment for the **Data Summarization** module (Class 5). The goal was to analyze a 3-year transactional dataset of an electronics retailer using Pivot Tables and Advanced Excel Formulas to identify regional trends and product performance.

## 📝 Project Objective
To transform raw sales data into meaningful insights to assist management in decision-making regarding **Regional Strategy** and **Product Inventory**.

## 🛠 Key Skills Applied
* **Pivot Tables:** Created dynamic summaries of `Total_Sales` by Region and Year to track growth.
* **Conditional Formulas:** Used `SUMIFS`, `COUNTIFS`, and `AVERAGEIFS` to extract granular insights (e.g., Laptop sales in 2024).
* **Data Visualization:** Built Pivot Charts to visualize the performance gap between the North and South regions.
* **Lookup Functions:** Applied `XLOOKUP` and `VLOOKUP` for data mapping.

## 🔍 Key Insights Discovered
1.  **Top Region:** The **North** region is the consistent market leader.
2.  **Growth Spike:** The **South** region saw a **600% growth** in 2025 after shifting strategic focus to Mobiles/Tablets.
3.  **Best Product:** `NovaPhone X` is the highest revenue generator.
4.  **Customer Segment:** Retail customers generate significantly more revenue than Wholesale or Online channels.
